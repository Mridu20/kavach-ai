# Sovereign AI Workbench

A self-hosted, on-premise agentic AI workbench for confidential industrial work.
No cloud calls. No external data transfer. Local models, local RAG, local tools.

## Structure
- `frontend/` — React + TypeScript UI
- `backend/` — FastAPI + agent orchestration + tools + RAG + generators
- `knowledge_base/` — SOPs, manuals, sample reports
- `sandbox/` — Docker sandbox for tool execution
